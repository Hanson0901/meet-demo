# 系統總覽

## 目標
建立一個能處理會議音訊、辨識說話者、產出逐字稿、整理摘要與待辦，並可即時輸出 log 的生成式會議助手。

## 設計原則
- 所有流程以模組化設計，便於在 `Windows` 與 `Raspberry Pi 5 16GB` 之間切換。
- 語音處理與 LLM 推理分離，避免單一模組過度耦合。
- 所有輸出都保留 `timestamp`、說話人與處理狀態。
- 所有模組都必須能輸出統一格式的即時 log。

## 系統流程
1. 收音或載入錄音檔。
2. 進入 `FunASR` 辨識與說話人區分。
3. 寫入資料庫。
4. 進行繁體轉換。
5. 由 `Gemma 4` 進行摘要、決議、待辦與問答生成。
6. 透過 CLI 或 Web UI 顯示結果。

## 輸出內容
- 逐字稿
- 說話人紀錄
- 會議摘要
- 決議清單
- 待辦事項
- 可搜尋的會議知識庫
