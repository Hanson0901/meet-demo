# 介面與部署層

## 職責
提供兩種使用方式：
- 一鍵執行模式
- Web 介面模式

## 一鍵執行模式
適合快速開始會議錄音與整理。
- 啟動錄音
- 自動辨識
- 自動產出摘要
- 自動匯出結果

## Web 介面模式
適合需要互動、搜尋與回放的情境。
- 上傳音檔
- 即時觀看逐字稿
- 查詢歷史會議
- 檢視說話人與待辦

## 部署建議
- `Windows`：適合作為主要推理與 Web 服務主機。
- `Raspberry Pi 5 16GB`：適合作為前端收音、邊緣節點或輕量部署環境。

## 建議技術切分
- 前端：Web UI
- 後端：API 服務
- 背景任務：ASR、整理、摘要
- 儲存：資料庫與檔案系統
