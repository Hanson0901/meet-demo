# 會議記憶與資料庫層

## 職責
保存所有會議內容，讓系統可以查詢歷史會議、追蹤人物、重建上下文。

## 建議資料表
- `meetings`
- `speakers`
- `utterances`
- `actions`
- `decisions`
- `logs`

## 資料關聯
- 一場會議對應多個說話人。
- 一位說話人對應多段語音紀錄。
- 一段逐字稿可對應多個待辦或決議。

## 保存內容
- 原始辨識文字
- 繁體轉換後文字
- 時間戳記
- 說話人標記
- LLM 生成摘要
- 待辦與決議

## 查詢能力
- 搜尋某場會議的關鍵字
- 依人物查詢過往發言
- 依日期匯出會議記錄
